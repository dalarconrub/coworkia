# /canvas

## Propósito

Crear o editar **JSON Canvas** (ficheros `.canvas` de Obsidian).

## Skill obligatoria

Carga y aplica **antes** de modificar o proponer contenido:

```text
.ai/skills/obsidian-skills/skills/json-canvas/SKILL.md
```

## Instrucciones

1. Lee `SKILL.md` y ejemplos en `references/` si aplica.
2. Aplica el esquema y convenciones al resto del mensaje tras `/canvas`.
3. Valida que el JSON sea coherente con el formato esperado por Obsidian.
