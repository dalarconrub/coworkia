# /handoff

## Propósito

Crear un resumen operativo para continuar el trabajo en otra sesión, agente o persona.

## Entrada esperada

Estado actual del repo, tarea o conversación.

## Instrucciones

Sé concreto. Incluye decisiones tomadas, archivos tocados, comandos ejecutados, problemas pendientes y próximos pasos.

## Salida

```markdown
# Handoff

## Objetivo

## Estado actual

## Decisiones tomadas

## Archivos relevantes

## Cambios realizados

## Comandos ejecutados

## Problemas abiertos

## Próximos pasos

## Riesgos

## Contexto mínimo para retomar
```
