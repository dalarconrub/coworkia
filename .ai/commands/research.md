# /research

## Propósito

Investigar una cuestión técnica, científica o de producto con trazabilidad.

## Entrada esperada

Pregunta de investigación, comparación de herramientas, librerías, frameworks o enfoques.

## Instrucciones

Si hay acceso web o a documentos, usa fuentes primarias cuando sea posible. Distingue hechos, inferencias y opinión técnica.

## Procedimiento

1. Reformula la pregunta.
2. Define criterios de evaluación.
3. Busca o enumera fuentes relevantes.
4. Sintetiza hallazgos.
5. Compara alternativas.
6. Declara incertidumbre.
