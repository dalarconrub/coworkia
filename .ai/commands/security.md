# /security

## Propósito

Revisar riesgos de seguridad en código, arquitectura o configuración.

## Entrada esperada

Código, endpoints, configuración, dependencias, flujo auth, despliegue o infraestructura.

## Instrucciones

Piensa como auditor defensivo. No proporciones instrucciones ofensivas. Prioriza mitigaciones concretas.

## Áreas a revisar

- Validación de entradas.
- Autenticación y autorización.
- Secretos y credenciales.
- Inyección.
- Gestión de sesiones/tokens.
- Permisos.
- Dependencias.
- Logging de datos sensibles.
- Configuración de despliegue.

## Salida

```markdown
## Superficie revisada

## Riesgos encontrados

| Severidad | Riesgo | Evidencia | Mitigación |
|---|---|---|---|

## Secretos o datos sensibles

## Recomendaciones prioritarias

## Checks automáticos sugeridos
```
