## Ruta de Aprendizaje Recomendada

### Si eres nuevo usuario:
1. Lee [Guía de Inicio Rápido](quick-start.md)
2. Practica con los ejemplos básicos
3. Consulta [Guía de Usuario](guia-usuario.md) para funciones avanzadas

### Si quieres desarrollar:
1. Lee [Guía de Inicio Rápido](quick-start.md) para entender el sistema
2. Revisa [Arquitectura del Sistema](arquitectura.md)
3. Estudia [Guía de Desarrollador](guia-desarrollador.md)
4. Consulta [Referencia de API](api.md) cuando necesites detalles

## Contribuir a la Documentación

Si encuentras errores o quieres mejorar la documentación:

1. Revisa el archivo correspondiente en `docs/`
2. Haz tus cambios
3. Asegúrate de que el formato Markdown sea correcto
4. Actualiza este índice si agregas nuevos documentos

## Formato de Documentación

Todos los documentos están en formato Markdown (.md) y siguen estas convenciones:

- Títulos con `#` para secciones principales
- Código en bloques con sintaxis resaltada
- Enlaces relativos entre documentos
- Ejemplos prácticos cuando sea posible

## Actualizaciones

La documentación se actualiza junto con el código. La versión actual corresponde a DMS v1.0.0.
